将获得的信息给AI进行分析，得到以下的权限提升流程（自己并没有沉下心了解这个File Browser用处）

**核心信息**

这是 File Browser 的命令行管理工具。因为 `fileadmin` 可以 **sudo 跑它**，等于是以 root 权限任意调用这个 CLI,这就直接给了我们 root。

**最有用的一点：“快速安装模式”**

帮助里写了这段：

> 如果数据库路径不存在，File Browser 会进入**快速安装模式**，自动创建一个新数据库，并用 `--username` 和 `--password` 选项创建第一个用户。

意思是，只要我们指定一个**不存在的数据库路径**，它就会新建一个库，并把第一个用户设成 admin,密码我们自己定。而且这个进程是 root 跑的，新建的这个 admin 用户 scope 可以指到 `/`,权限全开——**等于拿到 root 的文件浏览器**。


```bash
sudo /usr/local/bin/filebrowser -d /tmp/pwn.db -r / --address 0.0.0.0 --port 9999 --username rootpwn --password RootPwn123456
```

这条命令做了这几件事：

- `-d /tmp/pwn.db`:指定一个不存在的数据库路径，触发快速安装
- `-r /`:根目录设成 `/`(整个文件系统)
- `--address 0.0.0.0 --port 9999`:监听所有接口的 9999 端口
- `--username rootpwn --password RootPwn123456`:创建 root 权限的新管理员

跑起来后，从你的 Windows 浏览器打开 `http://192.168.56.178:9999`,用 `rootpwn / RootPwn123456` 登录，就能以 root 身份浏览整个文件系统，`/root/flag.txt`、`/etc/shadow` 什么都能读。
