# 主动探测

## 1. Wappalyzer

Wappalyzer 可以自动识别网站上使用的技术，包括 CMS 平台、网页服务器、JavaScript 框架、分析工具、CDN 和数据库。它在浏览时被动运行，是快速技术指纹识别中最广泛使用的扩展之一。

## 2. ping

ping 是计算机网络中基础的诊断工具，用于测试本机与目标主机（IP 地址或域名）之间的网络连通性。它通过发送 ICMP（互联网控制报文协议）回显请求报文并等待回显应答来判断网络是否通顺，并测量往返时间（延迟）。

https://www.cnblogs.com/meiguicong/p/13357735.html

## 3. traceroute

该命令追踪数据包从你的系统到目标主机的路径。它的目的是发现路径上路由器（跳）的 IP 地址，并确定有多少跳点位于你和目的地之间。这些信息对于理解网络拓扑、识别过滤或延迟发生位置以及映射基础设施非常有用。

https://www.runoob.com/linux/linux-comm-traceroute.html

## 4. telnet

TELNET（电传打字机网络）协议于 1969 年开发，通过命令行接口与远程系统通信。该命令使用该协议进行远程管理，默认端口为 23。从安全角度看，telnet 以明文形式发送所有数据，包括用户名和密码。这使得任何拥有通信渠道访问权限的人都能轻松拦截登录凭证。安全的替代方案是 SSH（安全壳），它加密所有流量，是目前远程 CLI 访问的标准。

## 5. Netcat

Netcat（简称 nc）是一种多功能的网络工具，支持 TCP 和 UDP 协议。它可以作为客户端连接到监听端口，也可以作为服务器监听你选择的端口。这种双重功能使其在横幅抓取、端口探测、简单文件传输以及基础客户端-服务器通信中非常有用。现代版本，如 Nmap 项目中的版本，也支持 IPv6 和 SSL 加密，使其比传统工具如 telnet 更具灵活性。
