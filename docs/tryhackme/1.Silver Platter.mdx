## 二、漏洞验证

```bash

  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "Login=scr1ptkiddy&DomainId=0"
```

adm 组的核心权限：读取日志

根据 Debian 的官方定义，`adm` 组用于“系统监控任务”，其成员可以读取 `/var/log` 下的许多日志文件。简单来说，它的作用就是绕过权限限制，直接查看系统运行记录。

```bash
grep -iR "tyler" /var/log/ 2>/dev/null
```
