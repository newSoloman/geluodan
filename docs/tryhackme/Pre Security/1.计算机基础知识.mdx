# 计算机基础知识

本篇是 TryHackMe Pre Security 学习路径的第一篇笔记，从计算机最底层的硬件组成讲起，理清一台电脑是如何启动的、常见有哪些类型，再认识网络世界里客户端与服务器的协作方式、HTTP 的命令，最后简单了解虚拟化与云计算。把这些基础打牢，后面理解漏洞和渗透思路会更顺手。

## 一、计算机系统内部

把电脑看作一个"人"，每一块硬件都有它对应的"器官"。

### 1. CPU（中央处理器）= 大脑

它是电脑的"总指挥"，负责执行所有程序的计算和逻辑判断（比如算 1+1、判断要不要运行某个软件）。电脑快不快，CPU 是核心。

### 2. 主板 = 骨架 + 神经系统

它是那块最大的电路板，把 CPU、内存、显卡等都插在自己身上。"骨架"负责支撑所有硬件；"神经系统"（电路）负责让各个部件之间传递数据信号。

### 3. 内存（RAM）= 短期记忆

它负责存储你"当下正在处理"的事情，比如你现在打开的网页、正在编辑的文档。特点是速度极快，但一断电（关机）就全忘光了。内存越大，能同时处理的"眼前事"就越多（不卡顿）。

### 4. HDD + SSD（硬盘）= 长期记忆

它们负责存储你"长久保存"的东西，比如照片、电影、安装好的游戏。断电也不会丢。SSD（固态硬盘）像记性好、翻书快的现代人；HDD（机械硬盘）像老式档案室，容量大但找东西慢。

### 5. GPU（显卡）= 视觉皮层

它专门负责处理图像和画面，把电脑里的数据转化成你能在显示器上看到的精美画面。玩游戏、做 3D 建模就靠它，相当于大脑里专门管"看"和"成像"的区域。

### 6. PSU（电源）= 心脏和肺

心脏负责把家里的交流电（220V）"泵"成电脑能用的直流电（12V/5V 等），分配给所有硬件；肺负责吸气供氧，给硬件提供"能量"。没有它，整个机器直接"断气"罢工。

## 二、开机流程

认识了硬件的组成，再来看看按下电源键之后，一台电脑是如何一步步"醒过来"的。

### 步骤 1：按下电源键（心脏起搏）

就像你早上睡醒时深吸一口气，电源（PSU）收到"开工"信号，开始把电（氧气和血液）输送给全身所有零件。此时电脑各部件有了电，但大脑还是一片空白。

### 步骤 2：固件启动（脑干/本能苏醒）

身体（硬件）有电了，但大脑皮层（操作系统）还没上班。这时候，主板上的 UEFI（相当于脑干/本能区）开始工作。它不需要系统，是刻在"本能"里的底层代码，负责把 CPU、内存等核心部件先唤醒。BIOS 是它的老前辈，功能一样，只是 UEFI 是更先进的升级版。

### 步骤 3：开机自检（全身体检）

意识恢复前，先得确认身体零件都健全。UEFI 会运行一个叫 POST 的程序，像医生一样快速扫视：CPU 在不在？内存坏没坏？键盘鼠标插没插？如果哪个关键零件（比如内存条）没插好或坏了，电脑就会黑屏并发出一连串"滴滴"报警声（相当于身体发出疼痛警报）。

### 步骤 4：选择启动设备（寻找"记忆仓库"）

体检通过，身体完好，接下来该找回"长期记忆"了。UEFI 会按照预设的优先级顺序（相当于大脑说"先翻自己的记忆书，再看 U 盘里的笔记"），去查找哪个设备里装有操作系统。通常默认是硬盘（长期记忆），也可能是 U 盘或光驱。

### 步骤 5：启动引导加载程序（翻开"记忆目录"）

终于找到硬盘了，但系统文件那么大，不能一股脑全塞进大脑。所以硬盘开头有个"引导加载程序（Bootloader）"，相当于记忆书的目录或导航员。它负责把操作系统的核心（Windows 或 macOS 的内核）从硬盘（长期记忆）搬运到内存（短期记忆）里。当这个搬运完成，屏幕上才会出现 Windows 的徽标加载动画，此后操作系统正式接管大脑，你就看到桌面了。

## 三、计算机类型

按用途和形态，电脑大致可以分为下面四类。

### 1. 移动电脑（Mobile）

笔记本、平板、手机这一类"随身带"的设备。以便携和省电为优先，性能相对妥协，适合移动办公、上网、看视频。

### 2. 台式电脑（Desktop）

固定放在家里或办公室的电脑。零件可以自由更换升级，同价位下性能通常比笔记本更好，适合游戏、办公和 DIY 装机。

### 3. 工作站电脑（Workstation）

高性能台式机的"专业版"，专为 3D 建模、视频剪辑、科学计算等重负载任务设计，通常配备更强的 CPU、专业显卡和更大的内存。

### 4. 服务器电脑（Server）

7×24 小时不间断运行，专门"伺候"其他电脑（客户端）的机器——提供网页、文件、邮件等服务。可靠性、稳定性优先，大多跑在数据中心里。

## 四、客户端-服务器基础知识

理解了硬件，再看网络世界里最基本的"主仆"关系——客户端与服务器。下面五个概念是理解一切 Web 技术的地基。

### 1. Service（服务）、Client（客户端）、Server（服务器）

- **服务器（Server）**：专门负责"提供服务"的电脑或程序，如网站服务器、游戏服务器。
- **客户端（Client）**：主动发起请求、使用服务的程序，你用的浏览器就是最典型的客户端。
- **服务（Service）**：服务器上运行、对外提供特定功能的具体程序；当它运行起来时，我们就说服务器在"提供服务"。

### 2. Request and Response（请求与响应）

客户端向服务器"要东西"，叫**请求（Request）**；服务器处理完把结果"送回来"，叫**响应（Response）**。一往一来，构成了网络通信最基本的一问一答。

### 3. Protocol（协议）

双方沟通必须遵守的"共同语言/规矩"，规定了请求长什么样、响应怎么回。常见的有 HTTP、HTTPS、FTP。没有协议，两台机器就算连上也无法互相理解。

### 4. Port（端口）

服务器上每个服务的"门牌号"。一台服务器往往同时跑着很多服务，IP 地址负责找到机器，端口号负责把数据送到正确的那个服务。例如 HTTP 默认 80 端口，HTTPS 默认 443，SSH 默认 22。

### 5. DNS

全称 Domain Name System（域名系统），把人类好记的域名（如 `google.com`）翻译成机器用于寻址的 IP 地址（如 `142.250.190.46`）的"电话簿"，让用户不用记一串数字。

## 五、HTTP Commands

客户端-服务器里最常见的协议就是 HTTP，它定义了一系列"命令"（请求方法），客户端用它们告诉服务器自己想做什么。

| 方法 | 作用 |
|------|------|
| `GET` | 请求获取资源，只读，不会修改服务器上的数据 |
| `POST` | 向服务器提交数据、创建新资源（如表单提交、发表文章） |
| `PUT` | 整体更新/替换一个资源（上传完整的新版本） |
| `DELETE` | 删除服务器上指定的资源 |
| `PATCH` | 部分更新一个资源，只修改其中某几个字段 |
| `HEAD` | 与 `GET` 类似，但只返回响应头、不返回正文，常用于探测资源是否存在 |
| `OPTIONS` | 询问服务器支持哪些请求方法（常见于跨域请求的预检） |
| `CONNECT` | 在客户端与服务器之间建立隧道连接，常用于 HTTPS 代理 |
| `TRACE` | 让服务器把收到的请求原样回显，用于调试（也因此常被禁用，存在安全隐患） |

## 六、虚拟化基础知识

一台物理电脑只能装一个系统？虚拟化打破了这种"一对一"，让一台物理机同时跑多个系统。核心角色是 **Hypervisor（虚拟机管理程序）**——创建并运行虚拟机的"管家"软件，如 VMware、VirtualBox、KVM。

以下是这个房间里学到的关键术语：

**Virtualization（虚拟化）**：使一台物理计算机能够像多台独立的计算机一样运行（*Enables a single physical computer to act like multiple separate computers*）。

**Hypervisor（虚拟机管理程序）**：创建和运行虚拟机的"管理"软件（*The "manager" software that makes and runs the virtual computers*）。

**VM / Lab Machine（虚拟机）**：一台完整的虚拟计算机，位于真实计算机内部，拥有自己的系统（*A whole virtual computer inside the real one, with its own system*）。

**Container（容器）**：一个小型、独立的盒子，用于运行一个与主机共享同一系统的应用程序（*A small, isolated box for one app that shares the same system as the host*）。

**Container Images（容器镜像）**：用于创建容器的预打包配方/模板（*A pre-packed recipe/template used to create containers*）。

**Network Ports（网络端口）**：应用程序通过网络进行通信的特殊编号入口点（*Special numbered entry points that apps use to talk over the network*）。

## 七、云计算基础知识

把别人的服务器通过互联网"租"来用，就是云计算的思路。按"谁在用"和"管到什么程度"，可以分成下面这些概念。

**Public Cloud（公有云）**：通过互联网访问的、由许多人和公司共享的云服务（*Cloud services you access over the internet that many people and companies share*）。

**Private Cloud（私有云）**：专为一家公司打造的云平台，让该公司拥有更大的控制权和安全性（*A cloud built just for one company, so they have more control and security*）。

**Hybrid Cloud（混合云）**：公有云和私有云的混合体，可以协同工作并共享数据（*A mix of public and private clouds that can work together and share data*）。

**IaaS（基础设施即服务）**：从云端租用服务器和存储等基本计算机部件的服务（*A service where you rent basic computer parts like servers and storage from the cloud*）。

**PaaS（平台即服务）**：提供一个即用型环境，让您无需管理服务器即可构建和运行应用程序（*A service that gives you a ready-to-use environment to build and run apps without managing servers*）。

**SaaS（软件即服务）**：无需安装即可在线使用的软件，例如 Gmail 或 Zoom（*Software you use online without installing anything, like Gmail or Zoom*）。

**EC2**：亚马逊的云计算机，可以随时根据需要快速创建、使用和调整大小（*Amazon's cloud computers that you can quickly create, use, and resize whenever you need them*）。
