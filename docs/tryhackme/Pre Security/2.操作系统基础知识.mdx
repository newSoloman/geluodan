# 操作系统基础知识

本篇是 TryHackMe Pre Security 学习路径的第二篇笔记，接着上一篇的硬件知识，来认识操作系统这个"大管家"——它如何管理进程与内存、如何组织文件与用户，又通过哪些界面与我们交互，最后看看它在安全方面承担的责任。

## 一、操作系统介绍

操作系统（Operating System，OS）是连接硬件与应用软件的桥梁。用户通常不用直接跟硬件打交道，而是通过操作系统这个"中介"来使用电脑。下面五个职责就是它的核心工作：

| 责任 | 操作系统做什么 | 例子 |
|------|--------------|------|
| 进程管理（Process Management） | 创建、调度、确定优先级并终止正在运行的程序。操作系统决定每个进程获得的 CPU 时间，从而使多任务处理流畅无阻。 | 同时打开多个应用程序（浏览器、音乐播放器、社交媒体），电脑也不会卡顿。 |
| 内存管理（Memory Management） | 为进程分配 RAM，保护各应用的内存不被其他进程占用，并在应用关闭时回收内存；当 RAM 不足时，使用虚拟内存保持系统稳定。 | 同时打开多个应用时，操作系统为每个应用分配内存并相互隔离，避免互相干扰或崩溃。 |
| 文件系统管理（File System Management） | 将文件整理到目录中，处理命名、路径、权限和元数据（名称、大小、类型、时间戳）。 | 新建文件夹、保存照片、把文件设置为"只读"。 |
| 用户管理（User Management） | 处理多个用户账户、身份验证和权限，决定谁可以访问什么。 | 用密码登录，并确保其他用户账户无法访问你的文件。 |
| 设备管理（Device Management） | 加载驱动程序并提供统一接口（硬件抽象层），让应用程序只需说"打印这个"或"播放这个声音"。 | 插入新的鼠标、打印机或外置硬盘后，立即就能使用。 |

## 二、操作系统的关键术语

以下是操作系统相关的核心术语，理解它们能帮你更清楚地区分"系统底层"与"普通应用"：

**操作系统（Operating System / OS）**：管理硬件、应用程序和所有系统资源的核心软件（*The core software that manages hardware, applications, and all system resources*）。

**内核空间（Kernel space）**：操作系统拥有高度特权的区域，可以直接访问硬件；内核就住在这里，直接管理硬件和系统资源（*The OS's highly privileged area with direct hardware access, and the home of the kernel, which directly manages hardware and system resources*）。

**用户空间（User space）**：常规应用程序运行的区域。出于安全和系统稳定性的考虑，这里的权限受到限制（*The area where regular applications run with limited permissions for safety and system stability*）。

**图形用户界面（Graphical User Interface / GUI）**：操作系统的视觉部分，包括窗口、图标和菜单，让你通过点击和轻触进行交互（*The visual part of the OS, windows, icons, and menus, that lets you interact through clicking and tapping*）。

**命令行界面（Command-Line Interface / CLI）**：基于文本的界面，通过输入命令来精确、快速地控制系统（*A text-based interface where you type commands to control the system with precision and speed*）。

## 三、Windows 基础

Windows 是我们最常接触的操作系统。下面这些图形界面组件，就是日常使用电脑时打交道最多的部分：

| 组件 | 作用 |
|------|------|
| 桌面（Desktop） | 文件、文件夹和快捷方式存放的主要工作区域 |
| 任务栏（Taskbar） | 控制栏，提供对应用程序、工具、设置和通知的访问 |
| 开始菜单（Start Menu） | 访问应用程序、设置和电源选项的主要方式，以 Windows 徽标为标志 |
| 搜索（Search） | 通过输入搜索词，快速查找应用程序、设置和文件 |
| 文件资源管理器（File Explorer） | Windows 内置的浏览、管理和组织文件与文件夹的工具 |
| Windows Update | 内置更新工具，帮助保持操作系统、原生应用和安全功能为最新状态 |
| Microsoft Store | 用于安装受信任应用程序的 Windows 原生应用商店 |
| Windows 设置（Windows Settings） | 配置系统、设备、个性化和安全设置的集中位置 |
| 控制面板（Control Panel） | 访问系统配置选项的传统管理界面 |
| 任务管理器（Task Manager） | 实时监控系统运行状况的 Windows 工具 |
| Windows 安全中心（Windows Security） | 管理 Windows 内置安全工具的中央控制面板 |
| Windows Defender 防火墙 | 帮助保护系统免受未经授权网络流量侵害的防火墙 |

## 五、Windows CLI 基础知识

这个部分练习的是使用 Windows 命令提示符（CMD）完成操作，不再依赖鼠标点击：

- **无需点击即可浏览文件和文件夹**（*Navigate files and folders without clicking*）
- **即使不知道文件在哪里，也能找到它们**（*Locate files even when you didn't know where they were*）
- **显示隐藏的文件和目录**（*Reveal hidden files and directories*）
- **直接从终端读取文件内容**（*Read file contents directly from the terminal*）
- **收集基本系统和网络信息**（*Gather basic system and network information*）

这些都是 IT 与网络安全领域许多岗位都适用的基础技能（*These are foundational skills that apply across many roles in IT and cybersecurity*）。

## 六、操作系统安全

操作系统掌控着整台电脑，也因此是最常被攻击的目标。理解操作系统"如何保护自己"，也就理解了攻击者需要绕过的每一道防线。下面是最常见的几个安全防线：

### 1. 账户与权限（Accounts & Permissions）

遵循**最小权限原则**——日常使用标准用户账户，只有安装软件、修改系统时才临时使用管理员权限。Windows 的 UAC（用户账户控制）会在提权操作时弹窗让你确认，防止恶意程序悄悄获得管理员权限。

### 2. 身份验证（Authentication）

登录系统时需要证明"你是你"，方式包括：密码、PIN 码、指纹/人脸（Windows Hello），以及更安全的 MFA（多因素认证）。密码越长越复杂越好，不同账户不要复用同一个密码。

### 3. 系统更新与补丁（Updates & Patches）

操作系统和软件会定期发布补丁来修复已知漏洞，及时更新（如 Windows Update）能封堵绝大多数针对旧漏洞的攻击。很多真实入侵都发生在"打了补丁之前"的时间窗口里。

### 4. 防火墙（Firewall）

防火墙按照规则放行或拦截进出网络的流量，限制对外暴露的端口，降低系统被扫描和入侵的风险。Windows Defender 防火墙默认会拦截未经授权的入站连接。

### 5. 恶意软件防护（Anti-malware）

杀毒与端点防护软件（如 Microsoft Defender）实时拦截病毒、勒索软件、木马等恶意程序，并定期扫描系统。它是操作系统安全最直观的一道防线。

### 6. 数据加密（Encryption）

用 BitLocker 等工具对硬盘进行整体加密，即使硬盘被拆走，没有密钥也读不出其中的数据。这能保护设备丢失或被盗时的数据安全。

### 7. 日志与审计（Logging & Auditing）

系统会记录登录、权限变更等关键事件（Windows 中的事件查看器 Event Viewer）。安全人员正是通过这些日志来追溯入侵痕迹、判断攻击者做过什么。
