# Venus

HMVLabs 第一章：**Venus**——一个面向初学者的 Linux/CTF 综合靶机。

靶机内共有 **51 个连续任务**，每个任务会指引你找到下一个用户的密码，一路从 `hacker` 打到通关。虽然关卡简单，但覆盖了 Linux 使用、文本处理、编码解码、Web 请求、数据库、密码破解等大量基础知识点，非常适合练手。

**连接信息：**

| 项目 | 值 |
|------|----|
| Host | `venus.hackmyvm.eu` |
| Port | `5000` |
| User | `hacker` |
| Pass | `havefun!` |

## 一、连接靶机与任务机制

### 连接靶机

```bash
ssh -p 5000 hacker@venus.hackmyvm.eu
```

### 阅读 readme.txt

登录后先读一下主目录里的 `readme.txt`，它会告诉我们整个靶机的玩法：

```text
# EN
Hello hax0r,
Welcome to the HMVLab Chapter 1: Venus!
This is a CTF for beginners where you can practice your skills with Linux and CTF
so lets start! :)

First of all, the home of each user is in /pwned/USER and in it you will find a file called mission.txt which will contain
the mission to complete to get the password of the next user.
It will also contain the flagz.txt file, which if you are registered at https://hackmyvm.eu you can enter to participate in the ranking (optional).
And for a bit of improvisation, there are secret levels and hidden flags :D
You will not have write permissions in most folders so if you need to write a script or something
use /tmp folder, keep in mind that it is frequently deleted ...

If you have questions/ideas or want to comment us anything you can join
to our Discord: https://discord.gg/DxDFQrJ

Remember there are more people playing so be respectful.
Hack & Fun!
```

简单翻译一下：

> 你好，黑客（hax0r），欢迎来到 HMVLab 第一章：Venus！
> 这是一个面向初学者的 CTF 挑战，你可以在这里练习 Linux 和 CTF 技巧，那么，开始吧！ :)
>
> 首先，每个用户的家目录都在 `/pwned/用户名` 下，里面会有一个 `mission.txt` 文件，其中包含了获取下一个用户密码所需完成的任务。
> 同时里面也会有 `flagz.txt` 文件，如果你在 [hackmyvm.eu](https://hackmyvm.eu/) 注册了账号，可以把 flag 提交上去参与排名（非必须）。
>
> 另外，我们还即兴添加了一些隐藏关卡和隐藏 flag :D
> 大多数文件夹你没有写入权限，所以如果你需要写脚本或其他东西，请使用 `/tmp` 文件夹，注意该目录下的文件会被定期清理……
>
> 如果你有任何问题、想法，或者想跟我们聊聊，欢迎加入我们的 Discord 服务器。
> 请记住，还有其他人也在玩，请互相尊重。黑客愉快，玩得开心！

**机制总结：**

- 每个用户的家目录在 `/pwned/<用户名>` 下。
- 里面有两个关键文件：`mission.txt`（当前任务）和 `flagz.txt`（当前用户的 flag）。
- 完成任务后拿到**下一个用户**的密码，用 `su` 或 `ssh` 切换过去，继续下一关。
- 大部分目录没有写权限，需要临时写文件时用 `/tmp`。

> **任务描述**：用户 sophia 把她的密码保存在当前文件夹里的一个隐藏文件中，找到它并登录为 sophia。

hacker@venus:~$ ls

isla@venus:~$ grep '^a9HFX' passy | cut -c 6-

## 总结

Venus 作为 HMVLabs 第一章，用 51 个由浅入深的任务把 Linux 基础操作串了一遍：

- **文件查找**：`find`（按名称、大小 `-size`、属主 `-user`、属组 `-group`、修改时间 `-mtime`）、`whereis`
- **文本处理**：`grep`（行首 `^` / 行尾 `$`）、`sed`（指定行、正则提取）、`cut`、`sort` + `uniq`（去重 / 找重复）
- **编码解码**：Base64、十六进制（`xxd -r`）、摩斯密码、QR 码、图片隐写（`strings` / `exiftool`）、ISO / zip / tar 压缩包
- **权限利用**：`sudo`、`doas`、SSH 私钥登录、vim 交换文件恢复、bash 历史泄露
- **Web 相关**：HTTP 请求方法（PUT）、User-Agent、自定义 Header、本地 Web 服务、MySQL、DNS TXT 记录
- **密码破解**：`zip2john` + `john` 爆破 zip、`john` 爆破 MD5 哈希、枚举暴力破解

拿下全部 51 关 flag 后，HMVLabs 第一章 Venus 就正式通关了。Hack & Fun！
